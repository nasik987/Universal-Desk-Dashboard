Universal Desk Dashboard

Web installer for CYD / ESP32-2432S028, including CYD 2USB ST7789. No Arduino IDE required.

v0.3 · Full-screen clock · Swipe pages · Weather forecast · Focus timer · MakerWorld stats

1Connect the CYD to your computer by USB.
2Open this page in Chrome or Edge.
3Click Install and select the ESP32 serial port.
4Keep existing settings when updating. On first boot, choose Wi-Fi on screen.
Use Chrome or Edge on desktop.

Flashing replaces the firmware currently stored on the CYD. You can re-flash the original firmware later.
